# Workshop-ModernCSharp
A collection of lab exercises to go along with my one-day Modern C# hands-on workshop. If you aren't a student of the workshop, you're still free to clone or fork this repository, but keep in mind that I'm not accepting PRs or suggestions about the code in here. This is designed to help workshop attendees practice the Modern C# syntax, not accomplish any production-quality ends.

    > The lawyers made me say that. I swear all the code is good, though--I even asked an AI about it and [it said it was fine](https://www.instagram.com/p/DfG9CliyQ0a/).

You will not be able to make changes to my repository. If you want to be able to preserve your changes across labs, you'll need to either `git stash` your changes each time, or, if you have not already, fork this repo so that you can make commits and changes to your own copy.

This `main` branch contains the overall picture of the lab manual, and each of the hands-on labs are in their own branch. Each branch will have a `STEPS.md` file that contains the step-by-step directions.

Alternatively, if you don't want to (or aren't able to, due to corporate laptop restrictions), you can view the instructions in the GitHub interface by switching the UI to each branch and viewing the `STEPS.md` file for that branch.
